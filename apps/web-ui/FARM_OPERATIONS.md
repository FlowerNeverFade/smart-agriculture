# 农务执行前端说明

本分支实现今日农务、工单看板、巡田记录、水资源调度与执行状态。页面保持 REST/SSE 边界，浏览器不直接连接 MQTT。

登录页面、会话管理和 JWT 获取由队友的登录功能分支负责，本分支不提供登录入口，也不处理登录跳转。农务模块只消费上层传入的用户角色；尚未合并登录分支时使用 `MOCK_DATA.currentUser` 进行独立演示。

## 运行模式

- 在线模式：农务模块通过现有 API 客户端调用后端接口；登录分支合并后，由统一认证层提供用户身份和访问令牌。
- 本地演示：后端未启动时自动使用 Mock 数据，便于独立验收工单、巡田和资源排程交互。
- API 地址：同源部署时留空；本地静态服务默认尝试 `http://localhost:8080`，也可通过 `window.AGRILOOP_API_BASE` 或已有的 `agriloop_api_base` 配置覆盖。

## 模块与接口

| 功能 | 前端入口 | 后端接口 |
| --- | --- | --- |
| 今日农务 / 工单 | `#view=work-orders` | `GET /api/v1/work-items/today`、`GET/POST /api/v1/work-orders` |
| 巡田记录 | 工单中心内的“录入巡田记录” | `GET /api/v1/plots/{plotId}/inspections`、`POST /api/v1/inspections` |
| 水资源排程 | `#view=resource-coordination` | `POST /api/v1/resource-plans/evaluate` |
| 执行状态 | 工单看板与排程页关联列表 | 复用工单状态字段 |

农务任务统一为 `OPEN → ASSIGNED → IN_PROGRESS → DONE`。人工巡田数据标记为 `USER_PROVIDED`，不覆盖设备遥测；资源不足时必须显示未满足地块、缺口水量和原因。

## 角色能力展示边界

- `FARMER`：只读查看。
- `FIELD_OPERATOR`：认领、执行、完成工单，可录入巡田记录和发起资源评估。
- `FARM_ADMIN` / `SYSTEM_ADMIN`：拥有农务派发与执行操作入口。

上述映射只服务于农务模块的交互展示，不承担登录和认证职责。最终授权仍以后端 RBAC 校验为准；合并登录分支时，只需把登录后的用户对象传入农务模块上下文。

## 今日农务透明农田沙盘

- `#view=work-orders` 使用接近全屏的透明玻璃弹窗，背景保留 Home 环境轮廓，并叠加地块网格、地块边界、晨雾、露珠和低频扫描光；这些效果只承担信息氛围，不改变任务事实。
- “今日执行藤蔓”按截止时间展示筛选后的任务节点，节点颜色只表达优先级与状态；点击节点会打开右侧巡田抽屉，并自动带入关联地块与任务上下文。
- 鼠标在沙盘任意区域移动会形成约 1 秒衰减的绿色叶脉、露珠和叶片轨迹；点击任意区域会出现扩散土壤环、粒子与短时萌芽反馈。开启系统“减少动态效果”时停用背景持续动画与交互粒子。
- 原有四态拖拽看板、筛选、任务状态流转、新建工单和巡田提交逻辑继续保留；巡田记录仍以 `USER_PROVIDED` 保存，不覆盖传感器遥测。
- 巡田抽屉使用右侧透明布局，包含地块、时间、土壤表象、作物状态、设备外观、便携仪数值、现场说明与本地照片预览；照片当前仅本地预览，不声明已上传服务器。

## 水资源球舱可视化

- 排程弹窗以一个占据窗口主体的透明水球作为动态背景，水球按“今日剩余水量 / 每日总配额”计算真实液面；当前演示值为 `3,760 / 5,000 L`，来源明确标记为 `SIMULATED`。
- 前景水量面板独立展示精确余量、百分比、总配额、管网流量和本轮可调度容量，用户既可通过背景液面快速判断，也可读取明确数值。
- 排程评估只生成“试算后水位”，不会回写或降低实际水位；后端返回正式资源状态后，再通过统一资源状态入口更新实际水位。
- 水波与粒子画布覆盖整个排程弹窗：鼠标在任意内容区域移动都会产生衰减水波，点击任意区域都会产生短时水花和液滴。触摸设备不启用移动轨迹，系统开启“减少动态效果”时停用持续动画和粒子反馈。
- Home 右侧水资源卡片使用同一状态同步显示剩余比例、排程状态与试算分配量；关闭弹窗后仍保留本次排程试算摘要。
- 服务器接入时可调用 `setResourceWaterProfile(profile, provenance)` 注入观测到的容量、已用量、剩余量和流速；当前后端尚未提供独立资源档案查询接口，因此不得把 Mock 水位标记为真实观测。

## 本地验收

```powershell
python -m http.server 4173 --directory apps/web-ui
```

打开 `http://127.0.0.1:4173/index.html`。在线联调前需启动 API 服务，并确保 Spring CORS 允许静态页面的来源；也可采用同源反向代理部署。

建议合并前完成：四种角色上下文的按钮权限、工单全状态流转、巡田记录入库、水资源容量边界（总需求等于/小于/大于容量）以及 401/403 错误回归。登录页面和登录流程由认证功能分支单独验收。
