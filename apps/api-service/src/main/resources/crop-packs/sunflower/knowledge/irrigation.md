# 向日葵田间栽培指导

向日葵耐旱但怕涝，现蕾至开花结盘期是需水关键阶段。以下内容为重庆演示参考，品种、土质和降雨不同需重新校准。

## 出苗期与现蕾期

- 出苗期保持适度墒情，避免大水漫灌；现蕾期根据土壤湿度趋势和有效降雨安排补水。
- 重点巡查叶片萎蔫、根区积水和倒伏风险，人工观察与遥测分别保存。

## 开花结盘期

- 开花结盘期适度供水，土壤湿度参考 20%~38%；高温强光时优先清晨或傍晚补水。
- 暴雨后先清沟排水，不能在未核对根区和天气的情况下追加灌溉。

## 灌浆成熟期

- 灌浆后期逐步减少灌水，保持田间不过湿，避免倒伏和病害风险。
- 数据质量不足、传感器漂移或设备离线时先巡田复测，不生成可执行处方。
