# 玉米田间栽培指导

玉米拔节至灌浆期需水增加，抽雄吐丝期是需水关键期。以下内容为重庆演示参考，地块土质、降雨和品种不同需重新校准。

## 播种出苗期

- 保证出苗所需的墒情，避免大水漫灌造成板结和缺氧；雨后及时查看排水。
- 巡田同时记录出苗率、叶片卷曲和土壤湿度，人工观察不会覆盖遥测。

## 拔节期

- 植株快速生长时关注根区湿度趋势，灌溉遵循少量多次并结合有效降雨。
- 高温干旱时优先核对水源容量、设备能力和未来天气，再决定是否补水。

## 抽雄吐丝期

- 抽雄吐丝期对缺水敏感，土壤湿度参考 25%~45%，避免关键期持续失水影响授粉。
- 高温伴随干旱时安排清晨或傍晚灌溉；暴雨后先排水，不能直接追加灌溉。

## 灌浆成熟期

- 灌浆期保持适度墒情，成熟后逐步减少灌水，避免田间过湿影响根系和收获。
- 数据质量不足、传感器漂移或设备离线时先巡田复测，不生成可执行处方。
