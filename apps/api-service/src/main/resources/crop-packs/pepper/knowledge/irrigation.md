# 辣椒设施栽培指导

辣椒喜温但不耐涝，应保持根区见干见湿并避免积水。以下内容为重庆温室演示参考，品种、季节和土壤条件不同需重新校准。

## 育苗期与营养生长期

- 育苗期保持温度和基质湿度稳定，定植后逐步通风，避免低温高湿。
- 营养生长期水肥遵循少量多次，及时整枝、绑蔓并保持群体通风透光。

## 开花坐果期

- 适度控水有助于坐果；高温尤其夜温偏高时关注落花落果并核对通风条件。
- 高山或多雨环境优先避雨、防病和排水，不能用一次萎蔫直接判断缺水。

## 采收期

- 采收期参考土壤含水率 20%~40%，高温强光时优先清晨或傍晚补水，避免午后大水。
- 灌溉前核对水量、设备流量和水位；数据质量不足或传感器漂移时先巡田复测。
