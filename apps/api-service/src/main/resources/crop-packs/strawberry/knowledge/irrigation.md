# 草莓设施栽培指导

草莓根系浅、需水敏感，应保持根区水分稳定，避免忽干忽湿和长时间积水。以下内容为重庆温室演示参考，品种、基质和季节不同需重新校准。

## 缓苗期与营养生长期

- 定植后优先促进根系恢复，保持基质湿润、通气，避免连续大水造成烂根。
- 水肥一体化采用少量多次，施肥前确认过滤器、滴灌流量和根区湿度。

## 开花期

- 开花期维持稳定水分，避免叶面长时间潮湿；棚内湿度偏高时先通风排湿。
- 高温时优先清晨或傍晚补水，发现落花应区分高温、授粉、缺水和病害原因。

## 膨果/采收期

- 膨果期避免忽干忽湿，过湿易增加灰霉病等风险；灌溉时间以根区反馈和设备流量为准。
- 草莓对盐害敏感，肥液应充分过滤并少量多次供应，禁止直接套用固定剂量。
- 传感器漂移、设备离线或数据质量不足时只做巡田和复测，不生成可执行处方。
