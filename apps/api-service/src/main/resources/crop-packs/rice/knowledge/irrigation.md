# 水稻田间水分管理指导

水稻不同生育期需水差异明显，不能把温室土壤湿度规则直接套用到稻田。以下内容为重庆演示参考，田块、品种、土壤和降雨不同需由当地农技人员校准。

## 秧苗期

- 保证秧苗成活和根系恢复，保持适度湿润，避免长时间深水或断水。
- 低温、阴雨时减少不必要灌水并加强排水，巡查叶色、根系和田面状态。

## 分蘖期

- 分蘖期保持浅水或湿润管理，结合田面水位、土壤湿度和有效降雨调节。
- 分蘖达到目标后不盲目加深水层，避免群体过密和根系缺氧。

## 抽穗扬花期

- 抽穗扬花期对水分和高温较敏感，避免关键期受旱；高温时核对水源与田面水位。
- 暴雨后先排水，设备或数据异常时先人工核验，不能由模型补造田面水位。

## 灌浆成熟期

- 灌浆期保持适度墒情，成熟前逐步减少灌水；收获前按农艺要求排水晾田。
- 传感器漂移、设备离线或质量不足时只做巡田和复测，不生成可执行处方。
