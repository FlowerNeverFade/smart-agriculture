>
> 实现基线：`admin@2b840bf`（`V4.2`）
>
> 适用角色：农场管理员（`FARM_ADMIN`）
>
> 文档性质：开发分工与历史复用指引，不代表对应功能已经完成

## 1. 目标与边界

本计划用于补齐农场管理员从“看见问题”到“完成处置”的业务闭环，并将工作拆分为两条可以并行推进的开发路线。

本轮继续遵守以下边界：

- 基于当前 Vue 3 二维管理员界面增量开发，不恢复旧 3D FarmMonitor。
- 不恢复旧水球、旧右栏、四角色模型或历史页面视觉。
- 历史代码用于迁移业务状态机、接口调用和验收思路，不直接整文件或整分支回迁。
- 演示执行必须明确标记为 `SIMULATED`，不得描述为真实水泵或真实设备执行。
- 不修改 JWT、Token 和现有会话字段的语义；新增权限能力应沿用 `farmIds`、`plotIds` 和角色范围。
- 正式数据缺失时显示空状态或“—”，不得用未标记的模拟数据补齐。

6. 创建种植批次，并根据 Crop Pack 任务模板生成生产计划和工单。

### 4.2 推荐实施顺序

#### A1. 先冻结工单与成员合同

> 2026-08-25：本步骤已完成本地实现与验收。正式接口按冻结状态机保存完整操作记录；成员页从正式账号读取当前农场成员，分配弹窗按成员状态、农场和地块权限筛选农户，后端再次执行权威校验。成员新增、停用和授权编辑仍属于后续步骤。

> 2026-08-25：巡田证据持久化已按同一工单合同增量实现。结构化人工观察使用服务端证据编号持久化，关联工单时写入 `evidenceRefs` 与审计历史；农户提交和管理员验收直接读取该证据。照片上传仍不在当前事实合同内。

- 定义工单状态及合法转换。
- 明确管理员分配、农户提交、管理员验收和退回的权限。
- 新增正式成员读取能力，确保任务执行人来自真实成员列表。

> 2026-08-25：本步骤已完成本地实现与验收。工单分配、执行、提交和验收仍属于后续 A 线步骤，不在本次完成范围内。

## 5. 开发者 B：智能决策与经营闭环

### 5.1 负责范围

开发者 B 负责管理员的“诊断、决策、资源、经营”闭环：

2. 地块诊断、支持/反对/缺失证据和决策就绪度。
3. 灌溉处方、人工确认、虚拟执行、ACK、效果评价和决策护照。
4. 多地块水资源容量试算和协同排程。
5. Crop Pack 查看器。
6. 价值对账。
7. 模拟器状态、刷新、启动和停止。

### 5.2 推荐实施顺序

#### B1. 先恢复诊断与灌溉事实链

按历史已验收顺序迁移为 Vue 状态：

```text
evaluateDiagnosis
  -> estimateIrrigation
  -> getDecisionReadiness
  -> 人工明确确认
  -> executeIrrigation
  -> 轮询 getCommand
  -> getCommandEvaluation
  -> getDecisionPassport
```

要求：

- 所有调用使用当前路由携带的 `plotId`，不得硬编码 A01。
- 低质量、传感器漂移或低就绪度不得生成可执行处方。
- `FAILED`、`PARTIAL`、`TIMEOUT` 不得显示为成功。
- 虚拟执行始终明确标记 `SIMULATED`。

#### B2. 恢复水资源排程

- 管理员输入或确认各地块需水量和优先级。
- 调用现有 `evaluateResourcePlan()`。
- 明确展示容量、分配量、缺口和未满足原因。
- 试算结果不得直接回写真实剩余水量。

#### B3. 恢复 Crop Pack、价值对账和模拟器入口

- Crop Pack 正式模式只显示后端真实返回字段。
- 价值对账区分计划、实际、基线和反事实，并保留来源标签。
- 模拟器不可用时显示环境原因，不提供假启动。

#### B4. 接通农场切换

- 加载当前管理员可访问的农场列表。
- 切换农场后统一刷新地块、任务、告警、设备和统计。
- 当前农场上下文必须传递到详情、诊断、排程和价值页面。

## 9. 必须优先处理的风险

### 9.1 今日任务范围

当前 `/work-items/today` 在不传 `plotId` 时会聚合所有任务，没有按当前用户的农场和地块范围过滤。多农场功能上线前必须修正。

### 9.2 农场选择器是假切换

当前选择器只更新前端变量，未驱动地块、任务、告警和设备重新加载；后端总览仍以演示农场为默认上下文。

### 9.3 当前灌溉是假执行

当前“正式下发指令”只在前端插入任务，没有调用已有的命令、ACK 和评价接口。修复前不得将其描述为已执行。

### 9.4 正式成员接口缺失

没有正式成员列表就无法可靠指定种植农户；演示成员不能用于正式会话。

### 9.5 旧模块可能混入模拟事实

历史 Crop Pack、资源排程和价值页面会使用 Mock 补齐字段。迁移时必须拆除这种正式数据与模拟数据混合方式。

## 10. 完成定义

任何功能标记为完成前，必须同时满足：
