# 农务与巡田界面调整验收记录

> 日期：2026-08-24  
> 模式：本地静态前端 + Mock 演示数据（`sourceMode=SIMULATION`）

## 1. 变更范围

- 输入：工作台左侧当前 `plotId`。
- 处理：农务模块按当前地块过滤任务和巡田证据；新建工单与巡田表单固定使用相同 `plotId`。
- 输出：状态统计、四态看板、最近巡田和底部执行藤蔓只展示当前地块内容。
- 交互调整：移除农务页光标追踪画布、指针事件和点击萌芽反馈；保留不响应光标的背景氛围层。
- 失败/降级：当前地块无任务时显示明确空状态；不回退展示其他地块任务。

## 2. 浏览器验收

| 用例 | 结果 |
|---|---|
| A01 打开农务模块 | 绑定提示为 A01；看板仅 1 张 `plot-a01` 任务卡 |
| 从左侧切换 A02 | URL 和绑定提示变为 A02；看板 2 张任务卡均为 `plot-a02`；藤蔓 2 个节点 |
| 新建工单表单 | 地块只读显示 A02，提交字段固定为 `plot-a02` |
| 光标特效 | 页面不存在 `[data-field-effects]`，模块不再导入或初始化指针追踪脚本 |
| 布局 | DOM 顺序为巡田记录在前、执行藤蔓在后 |
| 状态强调 | “待处理”“执行中”“紧急项”“今日已完成”四项标题均为 `15px`，计数均为 `32px` |
| 控制台 | 切换及打开表单后 error 日志为 0 |
