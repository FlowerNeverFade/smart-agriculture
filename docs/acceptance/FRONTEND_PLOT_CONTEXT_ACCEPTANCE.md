# 前端地块上下文联动验收记录

> 日期：2026-08-24  
> 范围：左侧“地块与作物”选择器与右侧功能子界面  
> 模式：本地静态前端 + Mock 演示数据（`sourceMode=SIMULATION`）

## 1. 变更合同

- 输入：用户点击左侧地块卡片，提供合法 `plotId`。
- 处理：统一更新 `currentPlotId`、左侧高亮、当前地块徽标和首页摘要；当前右侧视图重新接收同一 `plotId` 并刷新。
- 输出：URL `plotId`、模块标题、地块/作物数据和视图内部选中态保持一致。
- 失败/降级：未知 `plotId` 不修改当前上下文并显示错误提示；没有对应 Crop Pack 的作物仍停留在注册表管理视图，不推测不存在的作物参数。
- 范围边界：风险预测、时序监测、数字孪生、作物包、农务巡田和决策护照是地块上下文视图；经营价值与资源协同仍按农场级聚合展示，不伪装为单地块数据。
