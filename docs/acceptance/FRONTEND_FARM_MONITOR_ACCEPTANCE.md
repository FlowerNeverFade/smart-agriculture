# 农田动态监测前端验收说明

> 分支：`lxh-frontend`
> 状态：待团队验收
> 日期：2026-08-22

## 1. 实现范围

- 入口：`apps/web-ui/index.html#view=plot-detail&plotId=plot-a01`。
- 输入：浏览器当前时间、浏览器定位、Open-Meteo 当前天气、地块 Mock/后端数据、Crop Pack 作物与阶段上下文。
- 处理：同构图背景切换、Canvas 植被/水面/天气渲染、鼠标方向风场、空闲微风、地块状态与详情面板状态机。
- 输出：全屏农田动态场景、三块可交互地块、作物/阶段图层、预警、传感器指标、环境曲线、阶段时间线。
- 当前边界：双击地块只显示未来风险推演与情景模拟沙盘的预留入口，本阶段不实现沙盘页面。

## 2. 场景与降级路径

| 能力 | 正常路径 | 失败/降级路径 |
|---|---|---|
| 时间场景 | 06:00 开始日出，18:00 开始日落 | 可用 `demoTime` 固定演示，系统时间不可用时仍保留浏览器时间 |
| 实时天气 | 定位后请求 Open-Meteo，映射晴/多云/阴/小雨/中雨/大雨 | 定位拒绝时回退重庆坐标；天气请求失败时保留最近状态 |
| 动态背景 | 场景视差、阳光/云影、树冠/作物风场、水面波纹和天气粒子持续刷新 | Canvas 图层初始化失败时保留同构图背景与交互层 |
| 作物/阶段 | 选择作物后全地块图层联动；阶段改变密度、高度和色泽 | `auto` 跟随每块地 Crop Pack，未知值回退番茄/营养生长期 |
| 地块详情 | 单击从地块位置平滑放大，显示5项传感器、双环境曲线和4阶段 | 无匹配地块时不打开面板；Escape/关闭按钮返回场景 |
| 风险沙盘 | 双击地块识别目标并触发入口 | 当前明确提示“入口已预留，本阶段不跳转” |

## 3. 自动化验收结果

使用本地 HTTP 服务与 Playwright + Microsoft Edge，视口为 `1440×1024`。

| 检查项 | 结果 |
|---|---|
| JavaScript 语法与 `git diff --check` | 通过 |
| 地块数量 | 3 |
| 预警图标数量 | 1，仅风险地块展示 |
| 详情传感器数量 | 5 |
| 作物全场切换 | 三块地均由番茄/黄瓜/水稻/玉米选择驱动 |
| 阶段全场切换 | 三块地均切换为所选阶段；单块阶段节点可独立演示 |
| 双击地块 | 正确识别目标地块并显示沙盘预留提示 |
| 鼠标方向风场 | 指针向东移动后显示“向东风场”，指针风线可见 |
| 运动帧差 | 同场景前后两帧差异覆盖 `1440×1024` 全画面 |
| 浏览器运行时错误 | 0；未启动后端时 `/actuator/health` 404 按现有 API 适配器回退 Mock |

## 4. 精确时间边界

| 演示时间 | 场景状态 |
|---|---|
| `05:59:59` | 夜间 |
| `06:00:00` | 日出进行中 0% |
| `06:30:00` | 明亮白昼 |
| `17:59:59` | 明亮白昼 |
| `18:00:00` | 日落进行中 0% |
| `18:20:00` | 暮色过渡 0% |
| `18:45:00` | 夜间 |

## 5. 演示参数

为便于答辩复现，可在查询字符串中使用：

```text
?demoTime=18:10:00&demoWeather=sunny#view=plot-detail&plotId=plot-a01
?demoTime=14:20:00&demoWeather=heavy-rain#view=plot-detail&plotId=plot-a01
```

`demoWeather` 允许值：`sunny`、`cloudy`、`overcast`、`light-rain`、`moderate-rain`、`heavy-rain`。
