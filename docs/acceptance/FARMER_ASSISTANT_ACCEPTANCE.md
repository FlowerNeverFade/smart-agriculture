# 农户端“农智助手”验收记录

> 验收日期：2026-08-30
> 范围：本地模拟会话、虚拟执行；不连接真实水泵、阀门或现场网关。

## 1. 功能清单

- 导航顺序为“灌溉系统 → 消息中心 → 农智助手 → 更多工具”，旧左下角“咨询 AI”入口和固定弹窗已移除。
- `#assistant` 使用单列连续对话布局：服务状态、当前地块、历史对话、新对话、快捷问题、回答来源、降级提示、依据展开和底部输入框均可见。
- 历史对话以右侧抽屉展示标题、关联地块、最后时间和消息数；新会话拥有独立 `conversationId`，首次发送后才写入演示历史。
- 农户白名单 Agent 工具为：开始/继续/提交本人任务、提交文字巡田记录、申请巡田/复测/设备检查补证、确认 `READY` 处方并执行虚拟灌溉。
- 写操作先展示目标、参数、风险、来源和 10 分钟有效期；农户确认或取消后才更新状态。虚拟灌溉结果明确标注“虚拟执行/模拟结果”。
- 传感器漂移、低质量、非 `READY`、资源/冷却/权限不满足及管理员越权请求均返回阻断或澄清，不生成执行卡。

## 4. 当前边界

本轮只支持文字对话和非流式回答；聊天页不上传图片，不提供语音或生产级多模态能力。正式会话使用后端持久化与鉴权，演示会话使用浏览器会话级存储；所有灌溉均为模拟结果。
