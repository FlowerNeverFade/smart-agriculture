# 农户端“农智助手”验收记录

> 验收日期：2026-08-30
> 范围：本地模拟会话、虚拟执行；不连接真实水泵、阀门或现场网关。

## 1. 功能清单

- 导航顺序为“灌溉系统 → 消息中心 → 农智助手 → 更多工具”，旧左下角“咨询 AI”入口和固定弹窗已移除。
- `#assistant` 使用单列连续对话布局：服务状态、当前地块、历史对话、新对话、快捷问题、回答来源、降级提示、依据展开和底部输入框均可见。
- 历史对话以右侧抽屉展示标题、关联地块、最后时间和消息数；新会话拥有独立 `conversationId`，首次发送后才写入演示历史。
- 农户白名单 Agent 工具为：开始/继续/提交本人任务、提交文字巡田记录、申请巡田/复测/设备检查补证、确认 `READY` 处方并执行虚拟灌溉。
- 写操作先展示目标、参数、风险、来源和 10 分钟有效期；农户确认或取消后才更新状态。虚拟灌溉结果明确标注“虚拟执行/模拟结果”。
- 普通冷却用于防重复点击；严重干旱且最新数据、设备健康、资源、权限和 `READY` 条件均满足时，可在确认卡中选择受限应急补水，仅绕过重复冷却。
- 传感器漂移、低质量、非 `READY`、资源/权限不满足及管理员越权请求均返回具体阻断或澄清，不生成执行卡。

复用 `http://127.0.0.1:3001/farmer.html#assistant` 本地页面完成一次集中验收：

1. 桌面视口：导航顺序、四个快捷问题、连续问答、回答依据与工具审计展开、历史抽屉、会话切换和新对话均通过。
2. Agent 闭环：文字巡田“预览 → 确认 → 已完成”通过；`READY` 虚拟灌溉“聊天内预览 → 确认 → 虚拟执行/模拟结果”通过；不再跳转旧建议页。
3. 窄屏视口（390px CSS 宽度）：工具栏自动换行，历史抽屉全宽，页面无横向溢出。

## 4. 2026-08-30 反馈修复验收

- 普通灌溉在冷却保护期间返回剩余时间；严重干旱（演示湿度 4%，应急阈值 8%）在确认时显示“受限应急补水”，并由 API/Web 回归验证正常执行、重复冷却阻断与幂等。
- 农智助手发送“执行当前地块灌溉”直接生成内联“操作预览”卡；点击“确认执行”后状态变为“已完成”，页面保留“虚拟执行/模拟结果”来源说明。
- 390px CSS 宽度实测 `scrollWidth === innerWidth === 390`，工具栏 `flex-wrap: wrap`；当前浏览器控制台未发现本地页面新增 warning/error。

## 5. 当前边界

本轮只支持文字对话和非流式回答；聊天页不上传图片，不提供语音或生产级多模态能力。正式会话使用后端持久化与鉴权，演示会话使用浏览器会话级存储；所有灌溉均为模拟结果，受限应急补水也不连接真实水泵、阀门或现场网关。
