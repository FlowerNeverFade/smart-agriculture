# 农户主面板信息层级验收

> 验收日期：2026-08-30  
> 范围：农户首页的信息层级、风险聚合、动态去重和响应式布局  
> 发布边界：本轮仅完成本地工作区验收，未执行公网部署；模拟数据和虚拟执行边界保持不变。

## 1. 本轮变更

- 首层改为“今天先做什么 + 当前风险”双栏，优先行动最多三项。
- 四项统计压缩为状态条，避免与任务和风险卡片重复争夺注意力。
- 地块概览提前到天气、设备辅助信息之前，地块卡保留下一步动作。
- 任务与普通通知合并为“最近动态”；告警集中在优先行动和风险区，不在动态区重复展示。
- 移动端 760px 以下默认收起侧栏，保留汉堡入口，主内容保持单列。

## 3. 浏览器验收

使用本地静态页面 `http://127.0.0.1:3000/farmer.html#dashboard`，演示会话，控制台无 warning/error。

| 场景 | 实际结果 |
|---|---|
| 宽屏首页 | 行动区、风险摘要、状态条、地块、辅助信息、最近动态按预期顺序渲染；页面横向溢出为 0 |
| 窄屏首页 | 侧栏默认收起；风险摘要单列；统计条双列；页面横向溢出为 0 |
| 双主题 | 点击主题切换后 `data-theme=dark`，再次点击可恢复 |
| 优先行动 | 点击“温室1 · 土壤湿度低于目标”可打开灌溉建议确认流程 |
| 任务入口 | “任务中心”进入 `#tasks` |
| 风险入口 | “查看风险建议”进入 `#advice` |
| 动态去重 | 首页动态过滤告警类消息；重复告警集中在风险摘要和优先行动 |
