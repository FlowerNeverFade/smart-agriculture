# 农场管理员地块稳定排序与拖拽排序

> 功能编号：T-144
> 当前状态：本地实现，待用户验收；本轮未推送或部署。

## 功能合同

- 管理员总览地块卡片支持约 400ms 长按拖动，普通点击仍打开地块详情，三点菜单仍执行编辑、停用、恢复和删除。
- 顺序偏好按“管理员账号 + 当前农场”隔离保存。不同账号、不同农场和农户端不会共享排列结果。
- 正式模式使用 `GET/PUT /api/v1/users/me/preferences/farm-admin-workspace?farmId=...`，演示模式使用同一隔离维度的浏览器本地存储。
- PUT 使用 `expectedRevision` 进行乐观并发保护；发生冲突时读取最新排列并回滚当前拖动，不使用任一侧覆盖另一侧。
- 新增、恢复或暂时缺失的地块按 `plotId` 稳定追加；刷新、切换路由和重新读取遥测只更新卡片内容，不改变已保存顺序。
- 指针取消、Escape、保存失败和切换农场会清理拖动状态；保存中的卡片不可再次发起拖动。

## 数据流

```text
当前授权 farmId + accountId
  -> 偏好读取（服务端 entity_record / 演示 localStorage）
  -> reconcilePlotOrder（已保存顺序 + 新地块稳定追加）
  -> 地块卡片渲染
  -> 长按 Pointer Events 重排
  -> expectedRevision 校验后持久化
  -> 成功保留新顺序；冲突/失败读取或恢复旧顺序
```

## 失败与权限边界

- 不是 `FARM_ADMIN`、未授权农场或跨农场地块 ID 均由后端拒绝；前端只展示当前农场范围。
- 偏好服务不可用时仍保留当前卡片和确定性顺序，拖动保存失败会提示并恢复上一次排列，不阻塞总览。
- 排序偏好只影响展示顺序，不改变地块、设备、遥测、任务或告警事实。
