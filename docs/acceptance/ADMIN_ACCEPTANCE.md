## 2. 核心闭环基线

原第 1 轮验收已并入本记录，历史独立报告和截图不再保留在当前工作树中。核心链路为：

```text
诊断
  -> 灌溉剂量试算
  -> 决策就绪度
  -> 人工明确确认
  -> 虚拟命令
  -> ACK
  -> 效果评价
  -> 决策护照
```

- 正式模式缺少 `plotId` 时返回 `PLOT_CONTEXT_REQUIRED`，不默认使用 A01。
- `SENSOR_DRIFT`、设备离线、证据不足或就绪度非 `READY` 时禁止执行。
- `PARTIAL`、`FAILED`、`TIMEOUT` 与 `SUCCEEDED` 分开展示，非成功结果不标记为完成。
- 虚拟执行始终标记 `SIMULATED`；剂量来自当前处方，不使用固定 153 L。
- 受限水源验收使用 3 块地申请 `1440 L`、容量 `900 L`、缺口 `540 L`，分配不超过容量且不回写真实剩余水量。
- 原轮次验收曾通过 Spring 20 项测试、Vite 构建及漂移拦截、失败回执和受限水量浏览器检查；当前实现继续由决策台、资源排程和后续综合回归覆盖。

## 5. 角色与固定场景回归

| 场景 | 结果 |
| --- | --- |
| `normal` | 正常地块和设备数据保持中性展示，不制造告警 |
| `drought` | 缺水诊断、处方、人工确认、虚拟命令和评价沿用既有闭环 |
| `sensor-drift` | 证据不足或冲突时进入补证，不绕过安全门生成可执行命令 |
| `device-offline` | 新设备和无心跳设备保持离线，状态可转检查任务 |
| 受限水源 | 沿用现有容量试算，分配不超过容量并展示缺口 |
| 工单通过/退回 | 生产计划和补证工单进入现有 `SUBMITTED -> DONE` 或退回生命周期 |
| 越权 | 跨农场设备绑定、地块和成员权限修改由后端拒绝 |
| 后端离线 | 正式会话不回退未标记 Mock；页面显示通俗失败或空状态 |
| 种植农户 | 进入农户工作台，不显示管理员页签 |
| 系统管理员 | 进入平台管理导航，不显示管理员页签 |
